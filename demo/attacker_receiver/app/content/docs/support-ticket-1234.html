Ticket #1234 — Login fails after password reset

Reporter: casey@example.com

Status: open

User reports that after resetting their password, the login form returns "Invalid credentials" even though the new password is correct. This was first reported on 2026-04-12 and we've reproduced it on staging.

Reproduction

  1. Sign in, click "Reset password".
  2. Follow the email link, set a new password.
  3. Try to log in with the new password.

Theories

  • Session token cache not invalidated after reset.
  • Email-link signing key rotated mid-reset.
